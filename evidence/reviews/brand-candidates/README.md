# Logo 候选与渲染证据

本目录只保存阶段 1 的候选和评审证据，不属于正式品牌资产。三个方向共同使用深蓝、青绿、琥珀和珊瑚红，避免依赖任何厂商配色或产品 Logo。

## 候选甲：并行轨道

三条轨道代表模型请求、工具执行和状态证据；弯折与汇合表达编排。它的优势是“多路进入、受控输出”一眼可见，主要风险是接近通用网络或数据管道图标。

## 候选乙：约束括架

左右边界代表 Harness 的约束面，中间轨迹代表一次任务从输入、核对点到执行结果。它与代码括号有轻微语义联想，但不直接复刻代码图标；主要风险是小尺寸下三个节点可能粘连。

## 候选丙：分层内核

三个错位层面代表接口、编排和执行，纵向轨迹把运行证据串起来。它最接近“内部剖面”的定位，主要风险是接近通用数据库、基础设施或技术栈图标。

## 固定压力测试

- 尺寸：16、24、32、64、128、256 像素。
- 背景：白色、深色、透明。
- 色彩：原色、灰度、纯黑单色。
- 识别：不应被看成机器人、聊天气泡、无限符号、厂商 Logo 或通用 AI 火花。
- 组合：与“Agent Harness 内部原理”中文标题并排时，标记不能压过文字，也不能依赖文字才能辨认。

候选评审完成前，`assets/brand/` 保持 `designing` 状态；只有最终赢家会生成正式资产。
